# Mission: Explain Multilingual LLM Costs

## Why
Explain to a public audience why Arabic and English can incur different LLM API costs without incorrectly claiming that UTF-8 bytes are billed. Build defensible multilingual API budgets.

## Success looks like
- Explain the difference between characters, UTF-8 bytes, and model tokens in plain language.
- Demonstrate a model-specific Arabic-versus-English token comparison.
- Produce a budget using measured input and output token counts for each language.

## Constraints
- Explanations must remain accurate across tokenizers and pricing changes.
- Prefer short, visual material suitable for a non-technical public audience.

## Out of scope
- Training or fine-tuning language models.
- General Arabic language processing.

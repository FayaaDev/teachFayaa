Session 01 · 12 minutes · D1

Find the signal, then name the paradigm

Your tangible win: classify an unfamiliar learning setup without memorizing five isolated definitions.

One deciding question

When a scenario asks for the learning paradigm, ignore the model name and ask:

Where does the correction signal come from?
Signal sourceParadigm
Human-provided target for each labeled exampleSupervised
Few labeled examples plus many unlabeled examplesSemi-supervised
Target automatically derived from each exampleSelf-supervised
No target; structure aloneUnsupervised
Cumulative reward from an environmentReinforcement

The Expert-level distinction

“Unlabeled data” does not automatically mean unsupervised learning. Masking a token and predicting it creates a definite target from the example itself. That is self-supervised. Unsupervised learning has no per-example target at all.

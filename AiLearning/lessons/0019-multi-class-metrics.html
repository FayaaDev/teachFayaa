Multi-class metrics

Your tangible win: name the simplest way to turn per-class F1 scores into one number when classes are imbalanced.

Worked example: Arabic dialect classification

A model classifies social-media posts into four dialects: Gulf, Levantine, Egyptian, and Modern Standard. The training set has 8 000 Gulf posts but only 800 Egyptian posts. Reporting a single accuracy number would hide poor performance on the rare Egyptian class.

Memory rule: use macro-average F1 when every class must be treated equally regardless of size.

Closed-book check

For the dialect classifier, which single number best shows performance on every class?

Session 02 · 12 minutes · D1

Choose the shape, then count the cost

Your tangible win: defend a supervised-model family by naming the target, the relationship shape, and the operational constraint.

The three-question filter

  1. What is the target? A continuous amount calls for regression; a category calls for classification.
  2. What shape must the model express? An additive global pattern supports a linear baseline. Many “if feature crosses threshold” interactions support trees.
  3. What constraint governs? Explainability, prediction latency, training time, memory, and scale can eliminate a technically capable family.
Expert move: do not select the most flexible model by default. Start with the simplest credible baseline, then add flexibility only when validation evidence and the operating constraints justify it.

Two ensembles, opposite mechanisms

Bagging / random forestBoosting
ConstructionMany learners built independently on randomized samples/features.Learners built in sequence; later learners focus on prior errors.
Main effectAggregate diverse predictions to reduce variance.Combine weak learners to reduce systematic error.
Memory cueBag = learners in separate bags.Boost = each learner gets a boost from the prior miss.

Both can use trees. “Uses trees” is therefore not enough to identify the method. The construction mechanism is the deciding evidence. scikit-learn’s ensemble guide describes bagging as randomized subsets aggregated to reduce variance, and boosting as sequential weak learners that focus on missed examples.

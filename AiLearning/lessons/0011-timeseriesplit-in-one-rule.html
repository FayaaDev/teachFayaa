TimeSeriesSplit in one rule

Your tangible win: state what n_splits actually controls and why the last fold is always the final validation set.

The rule

TimeSeriesSplit(n_splits=k) creates k validation periods. Training always grows from the earliest data up to—but never past—the start of each validation period. The final fold’s validation set is the most recent data you have.

Memory rule: n_splits = number of validation turns; the last turn always validates on the newest records.

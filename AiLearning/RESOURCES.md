# AI Engineer Expert Badge Resources

## Knowledge

- [Official AI Engineer badge record — Athka X, SDAIA](https://athkax.sdaia.gov.sa/badges/61af22d9-2e3e-4412-9675-e8b4504a7d20)
  Primary source for badge scope, assessment method, levels, eligibility, and registration status. It confirms Assistant, Associate, and Expert as the official English level names.
- [Official AI Engineer badge API record — English](https://athkax.sdaia.gov.sa/api/v1/public/badges/61af22d9-2e3e-4412-9675-e8b4504a7d20?locale=en)
  Machine-readable primary source useful when the public page is difficult to inspect.
- [Athka X national capability-building platform — SDAIA](https://sdaia.gov.sa/ar/Sectors/BuildingCapacity/Pages/athkax.aspx)
  Official context for the platform and its role in national data and AI capability building.
- [AI Engineer Badge Prep Log — Mohammed Al-Qarni](https://sdaia.qarni.me/)
  Third-party 14-session study plan used to organize this workspace. Strong preparation aid, but not an official SDAIA curriculum or sample exam.
- [National Occupational Standard Framework for Data and AI — SDAIA](https://sdaia.gov.sa/en/Research/Documents/PSFDataAndAIBook.pdf)
  Official occupational context for the AI Engineer role and production-oriented competencies.
- [AI Ethics Principles — SDAIA, 2025](https://sdaia.gov.sa/en/MediaCenter/KnowledgeCenter/ResearchLibrary/AIEthicsGuidelines.pdf)
  Current official English framework for ethics principles, controls, responsibilities, and risk classification.
- [Introduction to Machine Learning Problem Framing — Google](https://developers.google.com/machine-learning/problem-framing)
  Session 1 primary short course: deciding whether ML is appropriate and framing an ML solution.
- [Designing Machine Learning Systems, Chapter 1 — Chip Huyen](https://www.oreilly.com/library/view/designing-machine-learning/9781098107956/ch01.html)
  Session 1 source for production ML context. O'Reilly access may be required beyond the preview.
- [Designing Machine Learning Systems, Chapter 2 — Chip Huyen](https://www.oreilly.com/library/view/designing-machine-learning/9781098107956/ch02.html)
  Session 1 source for business and ML objectives, requirements, and problem framing.
- [Choosing the right estimator — scikit-learn](https://scikit-learn.org/stable/machine_learning_map.html)
  A rough algorithm-selection guide, not an exam blueprint or substitute for understanding constraints.
- [Machine Learning Crash Course: Linear Regression — Google](https://developers.google.com/machine-learning/crash-course/linear-regression)
  Session 2 primary source for continuous-target prediction and the form of a linear model.
- [Machine Learning Crash Course: Logistic Regression — Google](https://developers.google.com/machine-learning/crash-course/logistic-regression)
  Session 2 primary source for probability prediction in binary outcomes.
- [Decision Trees — scikit-learn](https://scikit-learn.org/stable/modules/tree.html)
  Session 2 reference for tree decision rules, classification, regression, and instability.
- [Ensemble Methods — scikit-learn](https://scikit-learn.org/stable/modules/ensemble.html)
  Session 2 reference for bagging, random forests, and sequential boosting mechanisms.
- [Support Vector Machines — scikit-learn](https://scikit-learn.org/stable/modules/svm.html)
  Session 2 reference for margin-based classification, kernels, and scaling considerations.
- [Neighbors-based Classification — scikit-learn](https://scikit-learn.org/stable/modules/neighbors.html)
  Session 2 reference for distance-based prediction, the choice of <em>k</em>, and nearest-neighbor trade-offs.
- [Clustering — scikit-learn](https://scikit-learn.org/stable/modules/clustering.html)
  Session 3 primary source for selecting a clustering algorithm from group shape, density, and noise handling.
- [Unsupervised Dimensionality Reduction — scikit-learn](https://scikit-learn.org/stable/modules/unsupervised_reduction.html)
  Session 3 reference for PCA and other methods that reduce the number of features without labels.
- [Preprocessing Data — scikit-learn](https://scikit-learn.org/stable/modules/preprocessing.html)
  Session 3 reference for categorical encoding, scaling, and feature transformations.
- [Common Pitfalls and Recommended Practices — scikit-learn](https://scikit-learn.org/stable/common_pitfalls.html)
  Session 3 primary source for preventing data leakage by fitting preprocessing only on training data and using pipelines.

## Wisdom (Communities)

- [MLOps Community](https://mlops.community/)
  Practitioner community for testing production architecture, reliability, evaluation, and operational tradeoffs against real experience.
- [AI Village](https://aivillage.org/)
  Security-focused practitioner community useful for adversarial ML and LLM application security discussions.

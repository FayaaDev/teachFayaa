Quick Reference · Session 01

Problem framing glossary

TermCompressed meaning
Supervisory signalThe correction source that tells a learner what to improve.
Supervised learningA human-provided target exists for each labeled example.
Semi-supervised learningA small labeled set plus a large unlabeled set from the same distribution.
Self-supervised learningA target exists for each example but is derived automatically from the data.
Unsupervised learningNo target; the method discovers structure such as clusters or dimensions.
Reinforcement learningAn agent learns a policy from cumulative environmental reward.
Unit of predictionWhat one prediction describes: transaction, customer-month, device-day, and so on.
Target variableThe exact observable outcome the model is trained to predict.
Prediction horizonHow far ahead prediction occurs; it must leave enough time to intervene.
Proxy mismatchThe measurable target differs from the real outcome the organization wants.
BaselineThe simplest credible solution against which ML must prove useful.
Retrieval rule: do not ask “Are there human labels?” Ask “Is there a target for every example, and where did it come from?”

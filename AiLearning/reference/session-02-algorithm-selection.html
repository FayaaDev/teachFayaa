Supervised algorithm selection

Choose the target type first. Then choose the simplest family that can express the relationship and satisfy the operational constraints.

FamilyUse whenCore caution
Linear regressionThe target is a continuous number and an additive linear relationship is a credible baseline.“Linear” describes the model in its features; engineered features can still represent curvature.
Logistic regressionThe target is a class and a fast, inspectable probability baseline is useful.The output is a probability; a decision threshold converts it into a class.
Decision treeThreshold-like, rule-shaped interactions matter and an individual prediction must be explainable as a path.A single deep tree has high variance: small data changes can yield a different tree.
Random forest / baggingA strong, variable base learner such as a deep tree overfits and robustness matters.Train diverse learners on random subsets, then aggregate. It primarily reduces variance.
Boosted treesA sequence of simple learners can improve residual errors and prediction quality justifies tuning.Learners depend on earlier learners; training and tuning are less parallel and need careful validation.
SVM / k-NNThe geometry is appropriate: margins for SVM; useful local neighbours for k-NN.SVM kernels and k-NN prediction can become costly at scale; feature scale matters.

Retrieval rules

Target first: continuous number → regression; category → classification. The algorithm name never determines the problem type.
Mechanism, not nickname: bagging = independent random subsets + aggregate; boosting = sequential correction of earlier errors.
Diagnostic: high training error and high validation error suggests high bias; low training error but much worse validation error suggests high variance.

Sources: Google: Linear Regression, Google: Logistic Regression, scikit-learn: Decision Trees, and scikit-learn: Ensembles.

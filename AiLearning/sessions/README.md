## Study loop

1. Study the session materials and its workspace micro-lessons.
2. Ask questions until the reasoning is clear.
3. Answer a closed-book quiz with new professional scenarios.
4. Review every explanation, including correct answers.
5. Record demonstrated learning and schedule spaced retrieval.

Each session contains direct links to selected study materials. Review the study map before reading so the material is used for the intended exam concepts.

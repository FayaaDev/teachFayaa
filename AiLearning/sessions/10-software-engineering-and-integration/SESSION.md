# Session 10: Software Engineering & Integration

**Status:** Locked until prior-session evidence  

## Outcome

Turn notebooks into testable modules, serve validated inference, package safely in containers, and test code, data, and model behavior.

## Study map

- Notebook to modules
- Dependencies and secrets
- FastAPI inference
- Multi-stage containers
- Code, data, and behavior tests

## Study materials

- [FastAPI: Bigger applications](https://fastapi.tiangolo.com/tutorial/bigger-applications/) — Covers moving notebook logic into testable modules and routers.
- [FastAPI: Containers](https://fastapi.tiangolo.com/deployment/docker/) — Covers validated inference serving, dependency locking, and container deployment.
- [Docker: Build best practices](https://docs.docker.com/build/building/best-practices/) — Covers multi-stage containers, minimal images, and reproducible dependencies.
- [Docker: Build secrets](https://docs.docker.com/build/building/secrets/) — Covers keeping credentials out of images and build arguments.
- [Ribeiro et al.: CheckList](https://aclanthology.org/2020.acl-main.442/) — Covers behavioral tests alongside code and data tests.

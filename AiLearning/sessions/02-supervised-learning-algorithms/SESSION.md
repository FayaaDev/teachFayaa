# Session 02: Supervised Learning Algorithms

**Status:** Ready to study  

## Outcome

Choose an algorithm family from relationship shape, data volume, explainability, and latency constraints; diagnose bias versus variance; distinguish bagging from boosting by mechanism.

## Study map

- Decision boundaries
- Linear and logistic regression
- Trees, bagging, and boosting
- Support vector machines and nearest neighbors
- Bias-variance tradeoff

## Study materials

- [Linear Models — scikit-learn](https://scikit-learn.org/stable/modules/linear_model.html) — Covers linear and logistic regression, decision boundaries, and regularization.
- [Decision Trees — scikit-learn](https://scikit-learn.org/stable/modules/tree.html) — Covers tree decision boundaries, complexity, and overfitting.
- [Ensemble Methods — scikit-learn](https://scikit-learn.org/stable/modules/ensemble.html) — Covers bagging, random forests, and boosting by mechanism.
- [Support Vector Machines — scikit-learn](https://scikit-learn.org/stable/modules/svm.html) — Covers support vector machines and margin-based decision boundaries.
- [Neighbors-based Classification — scikit-learn](https://scikit-learn.org/stable/modules/neighbors.html) — Covers nearest neighbors and the bias-variance tradeoff from model flexibility.

# Session 09: Customization, Agents & LLM Evaluation

**Status:** Locked until prior-session evidence  

## Outcome

Choose the least costly sufficient customization, explain LoRA, reason about compounding agent errors, evaluate LLM outputs, and defend structurally against prompt injection.

## Study map

- Customization spectrum
- LoRA
- Agents and error accumulation
- LLM evaluation
- Direct and indirect prompt injection

## Study materials

- [Hu et al.: LoRA: Low-Rank Adaptation of Large Language Models](https://arxiv.org/abs/2106.09685) — Covers LoRA and its position in the customization spectrum.
- [NIST: Generative AI Profile](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.600-1.pdf) — Covers choosing and evaluating GenAI controls across the lifecycle.
- [ITU-T F.748.46: Requirements and evaluation methods for AI agents](https://www.itu.int/rec/dologin_pub.asp?id=T-REC-F.748.46-202503-I%21%21PDF-E&lang=e&type=items) — Covers agent planning, memory, tool execution, and compounding-error risks.
- [NIST: Practices for Automated Benchmark Evaluations of Language Models](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.800-2.ipd.pdf) — Covers defensible LLM and agent evaluation design.
- [OWASP Top 10 for LLM Applications](https://genai.owasp.org/llm-top-10/) — Covers direct and indirect prompt injection and mitigations.

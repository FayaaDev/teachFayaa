The five-question decision routine

  1. Is there a target label? Yes → supervised; no → likely unsupervised.
  2. What form is the output? Category → classification; numeric value → regression.
  3. Which error hurts most? False positives → precision; false negatives → recall.
  4. Does it fail only on unseen data? Suspect overfitting, leakage, or drift.
  5. Does the answer need current private facts? Retrieve trusted documents (RAG), then validate.
Win for today: You will stop choosing a metric or an LLM technique by name alone. You will choose it from the risk described in the prompt.

Last-minute mental model

Before building

Define the target, data quality, error cost, privacy/fairness risks, and success metric.

Before deploying

Validate on held-out data, document limits, roll out safely, monitor performance and impacts, preserve human escalation.

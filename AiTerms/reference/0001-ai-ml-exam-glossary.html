Three-page AI/ML glossary

Use this for a fast second pass. For every term, ask: what problem does it solve, and when is it the wrong choice?

1 · Classical machine learning

Supervised learning

Learn from labeled examples (input → target). Classification predicts a category; regression predicts a number.

Unsupervised learning

Find structure in unlabeled data: clusters, anomalies, or lower-dimensional representations.

Overfitting

Fits training noise; training score is strong but new-data score weak. Reduce complexity, add data, regularize, or validate properly.

Bias / variance

High bias underfits (too simple). High variance overfits (too sensitive to training set). Balance both for generalization.

Cross-validation

Repeated train/validation splits (often k-fold) to estimate performance more reliably when data is limited.

Feature engineering

Create or transform useful input signals from raw data. Must be fit using training data only to prevent leakage.

Normalization / standardization

Normalization usually rescales to a bounded range, e.g. 0–1. Standardization makes mean 0 and standard deviation 1.

L1 / L2 regularization

Penalty on weights to curb overfitting. L1 tends to make some weights exactly zero; L2 smoothly shrinks all weights.

2 · Evaluation: select the failure you cannot afford

Precision

Of predicted positives, how many were right? Choose when false positives are costly.

Recall (sensitivity)

Of actual positives, how many were found? Choose when false negatives are costly.

F1 score

Harmonic mean of precision and recall. Useful when classes are imbalanced and both errors matter.

ROC-AUC

Threshold-independent ranking measure across true-positive/false-positive tradeoffs. It does not set the operating threshold.

Exam shortcut: Fraud review is expensive → favor precision. Missed cancer/fraud is dangerous → favor recall. Overall accuracy can deceive when positives are rare.

3 · Deep learning and LLMs

CNN

Neural network that uses local filters and shared weights; especially suited to spatial patterns in images.

Transformer / self-attention

A transformer uses attention to weigh relationships between tokens. Self-attention lets each token consider other tokens in the same sequence.

Token / context window

A token is a chunk of text processed by a model. The context window is the total token budget for input plus generated output.

Embedding / vector DB

An embedding is a numeric representation where semantic similarity is often spatial closeness. A vector database stores and searches these vectors.

RAG

Retrieve relevant external documents, then give them to the model as context. Best for current, attributable knowledge without changing model weights.

Fine-tuning / prompting

Prompting changes instructions/examples at inference. Fine-tuning updates behavior through additional training data; it costs more and needs evaluation.

Hallucination mitigation

Ground answers in trusted retrieved sources, constrain outputs, cite evidence, validate critical facts, and route high-risk cases to humans.

Quantization

Represent weights/activations with fewer bits to reduce memory and speed inference, usually accepting some accuracy trade-off.

4 · Operations and responsible AI

API / Docker / CI/CD

An API exposes a service interface. Docker packages software and dependencies. CI/CD automates build, test, and release steps.

Data / model drift

Data drift: live inputs change. Model/concept drift: the input→outcome relationship changes. Monitor both and retrain only after validation.

Blue-green / canary

Blue-green switches all traffic between two environments. Canary exposes a small share first, monitors it, then expands or rolls back.

Responsible AI

Assess fairness, protect privacy, document and explain decisions appropriately, establish governance, monitor impacts, and retain meaningful human oversight.

Printable reference & glossary · Your mission

1. A model contains learned numbers

Training adjusts numerical values called parameters. Most are called weights; for today's storage estimate, think of them as the model's learned numbers. They influence how the model turns an input into its next-token predictions.

27B means approximately 27 billion parameters. It does not mean 27 GB, 27 billion facts, or 27 billion words. Think of a huge mixing desk: parameter count is the number of adjustable settings, not the number of songs it knows.

2. Each number needs a representation

Imagine recording a setting as 0.123456 versus approximately 0.12. The shorter representation loses detail. This is an analogy: actual quantization uses binary codes and shared scales, not shortened decimal strings.

Quantization represents weights with fewer bits. A bit is a binary digit; 8 bits = 1 byte. Fewer bits reduce storage and can change model outputs. The number of parameters generally stays the same. [1]

3. Do one useful calculation

Weight storage in GB ≈ parameters in billions × average bits per weight ÷ 8.

4. Read your two labels

Q4_K_M is a named GGUF quantization preset in the roughly 4-bit family, not a promise that every stored weight costs exactly 4 bits. Supporting scales and mixed precision affect the effective average.

UD-Q2_K_XL is an Unsloth Dynamic preset in the roughly 2-bit family. Dynamic quantization allocates different precision to different parts of a model; “Q2” does not mean exactly 2 bits for every weight. Unsloth reports a 9.83 GB Qwen3.8-27B version. [2]

“Uncensored” describes a claimed behavior or model modification, not a storage format or a quality score. We need your exact model link to know whether both downloads come from the same checkpoint.

5. Storage is only the first fit check

Runtime memory ≈ loaded weights + conversation cache/state + working buffers.
Also leave room for the operating system and other applications.

A 9.8 GB file is not a guarantee of running inside 10 GB of available memory. Context length, model architecture, runtime settings, and CPU/GPU placement matter. A KV cache is extra memory used to reuse attention calculations. [3]

PS5LM's own model list gives this Q2 download as 9.15 GiB (about 9.83 GB) and makes fit conditional on its memory probe. The two units describe approximately the same size. [4]

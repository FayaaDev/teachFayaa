# Mission: Choose local models that fit

## Why
Compare local language-model downloads and choose versions that fit available hardware. Start by making sense of the user's comparison between a Qwen 27B uncensored Q4_K_M download and PS5LM's UD-Q2_K_XL download.

## Success looks like
- Distinguish parameter count, quantization, file size, and runtime memory.
- Estimate weight storage from parameter count and average bits per weight.
- Check model identity, available memory, context length, and runtime support before predicting fit.
- Compare quality using relevant evaluations rather than parameter count alone.

## Constraints
- Hardware, available memory, and intended workloads are not yet specified.
- Start with beginner-friendly explanations grounded in the supplied example.

## Out of scope
- None explicitly excluded by the learner.
